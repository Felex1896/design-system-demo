# Usage

Use an icon button when the glyph is enough. Use a labeled button when the action needs words.

## Size

| Size | Box | When |
| --- | --- | --- |
| large | 48 px circle | A hero action only. |
| medium | 36 px | The usual size. |
| small | 24 px | A dense row. |

## Color

| Color | When |
| --- | --- |
| `accent` | An important, priority action. |
| `success` | A confirmation. |
| `danger` | A destructive or dangerous action that cannot be undone. |
| `warning` | A dangerous action that can be undone. It needs extra attention. |
| `info` | An informational action, such as help or a hint. |

## Style

| Style | When |
| --- | --- |
| `solid` | The one most important action on the screen. |
| `faded` | A secondary action, beside the main button. |
| `transparent` | A tertiary action, beside the main and secondary buttons. |
| `outline` | An extra action outside that sequence. |
| `no-surface` | The lowest priority. A secondary extra action. |
